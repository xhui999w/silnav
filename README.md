# 我的导航 (nav-site)

极简网址导航，纯静态（单个 `index.html` + `sites.js`），无需后端，可挂 GitHub Pages / 内网 NAS。

## 特点
- **按访问地址自动切换内/外网**：页面读取自身被访问的网址（内网 IP 段 → 内网模式，否则外网模式），自动显示对应那一组链接，无切换按钮、不同时显示两套
- 顶部「NAS」分类始终显示，每个设备带内网 + 外网双地址；**点击图标时按当前环境自动选地址**（内网打开走内网、外网打开走外网）
- 自动抓网站 favicon，失败回退文字图标
- 搜索框：输入实时过滤链接，回车用当前引擎搜网页（按钮切换 百度/必应/Google）
- 分类可点击折叠，状态自动记住

## 使用
- **页面自助添加**：点右上角「+ 添加」→ 填名称 + 网址（或勾选 NAS 设备填内网+外网）→ 保存。链接存在浏览器本地，图标自动抓取；鼠标移到链接上点右上角「×」可删除。
- **高级 / 批量**：直接编辑 `sites.js`：

- `internalHosts` / `internalIpPrefixes`：哪些网址算内网（导航页自身被访问时用来判断）
- `nas`：顶部 NAS 设备，每个填 `internal`（内网地址）+ `external`（外网地址）
  ```js
  { name: "NAS 管理", internal: "http://192.168.1.10:5000", external: "https://nas.example.com" }
  ```
- `internal.categories`：内网环境下显示的分类（每个链接填 `url`）
- `external.categories`：外网环境下显示的分类
- `icon`（可选）：填 1 个字强制显示文字图标；不填自动抓 favicon

## 部署
- 同一份文件部署两份：
  - **内网**：NAS / 内网服务器（如 `http://192.168.1.10:9999`）→ 打开自动内网模式
  - **外网**：GitHub Pages 或公网域名 → 打开自动外网模式

> 只部署一边也完全能用，只是那一边只显示对应环境的分类。
