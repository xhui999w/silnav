# 我的导航（极简网址导航）

一个纯静态、零依赖的极简导航页。按访问网址自动区分**内网 / 外网**，分类横向密集排布，像 sun-panel 那样整齐但远比它轻量。

## 特性

- 无需后端、无需构建，三个文件直接打开即用
- 按 `location.hostname` 自动判断内网 / 外网，显示对应分类
- 分类标题带数量角标，点击可折叠，折叠状态自动记忆
- 链接为紧凑圆角小卡片，自动获取目标站 favicon，失败则显示文字首字
- 搜索框实时过滤链接，回车可直接用当前搜索引擎搜索
- 搜索按钮可在 百度 / 必应 / Google 之间切换
- 顶部“切换”按钮可手动覆盖内/外网，记忆上次选择（localStorage）

## 文件说明

| 文件 | 作用 |
|------|------|
| `index.html` | 页面与交互逻辑（一般不用改） |
| `sites.js`  | **你主要改这里**：标题、内/外网分类、链接、搜索引擎、内网判定规则 |
| `README.md` | 本说明 |

## 怎么改链接

打开 `sites.js`，在 `internal.categories` / `external.categories` 里增删分类和条目：

```js
{
  name: "分类名",
  links: [
    { name: "显示名", url: "https://..." },           // 自动获取 favicon
    { name: "显示名", url: "https://...", icon: "图" } // 强制显示文字图标
  ]
}
```

内网判定：命中 `internalHosts`（hostname 精确匹配）或 `internalIpPrefixes`（IP 前缀）即视为内网；其余（如公网域名、GitHub Pages）视为外网。

### 不想用 favicon？

把 `useFavicon` 改成 `false`，所有链接都只显示文字图标，更稳更快。

## 部署（同一份文件放两处）

“按登录网址自动分别”依赖**同一份文件同时部署在内网和外网**：

1. **内网**：把这三个文件放到你的 NAS / 内网服务器（例如 `http://192.168.1.10:8080/`）。
   在家或办公室打开它 → 自动识别为内网 → 显示内网分类。
2. **外网**：推到 GitHub 并开启 Pages（见下），或用公网域名反代同一份文件。
   在外面打开 → 自动识别为外网 → 显示外网分类。

> 只部署到一边也完全可用，只是那一边只会看到对应分组的链接。

### 开启 GitHub Pages

仓库 → Settings → Pages → Source 选 `main` 分支根目录 → Save。
几分钟后访问 `https://<用户名>.github.io/<仓库名>/` 即是外网版。

## 本地预览

直接双击 `index.html` 即可（此时 hostname 为 `localhost`，识别为内网）。
